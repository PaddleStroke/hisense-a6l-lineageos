# Eighth-pass offline reproductions

Evidence for F59–F61 in the [report](C:/Users/Pierre/Desktop/A6L/docs/hardware-review-round8-20260928.md). No phone, RF, ADB, firmware, real network-interface or production-source operations are performed.

```powershell
wsl --exec python3 /mnt/c/Users/Pierre/Desktop/A6L/research/hardware-review-round8-20260928/reproduce.py
```

Requires the existing WSL Python 3/g++ C++17 toolchain with ASan/UBSan and the local Android interfaces tree at `/home/a6l/android/a6l-lineage24/hardware/interfaces`.

The runner snapshots the current Windows radio source into a temporary WSL directory and `reviewed-source.zip`, archives the local NITZ AIDL contract, records SHA-256 hashes, builds the harnesses, and compares hashes after execution. **Rerunning replaces the evidence with the then-current source. Preserve this directory before rerunning if the original snapshot is needed.** The script does not replay automatically from the archive. A correction may make a defect assertion fail; these assertions are not acceptance tests for fixed code.

- `data.cc` compiles the complete production data manager, QMI client, encoders and existing fake modem. All network interface operations use recording `LinkOps`. A passive extra indication observer provides a dispatch barrier without changing production handling. F59 changes the fake modem's settings after successful setup. F60 delivers a disconnect before releasing an in-flight settings response. It records loss callbacks without performing the HAL's later queued teardown; the early case produces no callback to queue.
- `nitz.cc` compiles the exact extracted `onNitz` method with a recording Android indication and virtual elapsed clock. It checks the age/reference relationship, not full framework time selection, real suspend or clock setting.
- `framework-time-evidence.txt` was captured separately after the test run from the local Android framework. It contains excerpts and complete-file hashes supporting the meaning of receipt minus age. It is not generated by the runner.
