## 1. r6c boot loop: zygote_secondary aborts in eglGetDisplay (root cause confirmed, fixed)
Evidence: both tombstones are `Cmdline: zygote` (32-bit registers r0..r15 = app_process32 = zygote_secondary),
`Abort message: 'couldn't find an OpenGL ES implementation, make sure one of persist.graphics.egl, ro.hardware.egl and
ro.board.platform is set'`; kmsg `Service 'zygote_secondary' received SIGABRT` -> `process with updatable components

(onrestart), every ~10 s for the whole boot. props: `persist.graphics.egl=mesa`, `vendor.a6l.gpu=mesa`, `ro.zygote=zygote64_32`.
- `frameworks/native/opengl/libs/EGL/Loader.cpp`: the FIRST non-empty key of persist.graphics.egl / ro.hardware.egl /
  ro.board.platform is used and the loop `break`s - no fallback to `ro.hardware.egl=angle`. The r6c vendor image had Mesa only

## 2. USB: the charge guard disconnected the gadget while connected to the laptop (fixed)
Evidence (r6c kmsg 1309.4 s): `A6L_CHG_GUARD usb: soft_connect disconnect (online=0 [Unknown] SDP DCP CDP)` with adb bound
(`sys.usb.state=adb`, `sys.usb.ffs.ready=1`), then `dwc3 ... request ... was not queued to ep0out`, `udc a800000.usb: UDC had
already stopped`, adbd `read descriptors`. The guard's Q4 rule "online != 1 -> pull-up off" fired because pm660-charger
reported online=0/[Unknown] for a moment on a USB host (it had reported `online=1 ... SDP` at 37 s).
- **Fix (guard Q7, `power/rom/a6l-chg-guard.sh`)**: the only case that disconnects is a confirmed wall charger: `online=1`
  AND `usb_type [DCP]` AND the UDC has not seen a host (`/sys/class/udc/<udc>/state` not configured/addressed/default/
  suspended), on a gadget bound at this and the previous evaluation (Q6). Unplugged, [Unknown], [SDP], [CDP], anything else,
  or a host bus state never disconnect. The guard's own earlier disconnect is kept while unplugged (the next APSD still sees
  free D+/D- on a wall charger) and undone on anything but [DCP] or on a host state.
- Trade-off: a wall charger plugged in after a USB host (pull-up on) may be detected as FLOAT/SDP instead of DCP (no QC) until
  it is unplugged/replugged once; the guard never guesses a wall charger from [Unknown].
- Tests: `power/test/sim-power.sh` **A6L_POWER_SIM PASS** (16 new Q7 cases incl. the exact r6c situation: configured +
  online=0 [Unknown] -> connected; configured/addressed/suspended + [DCP] -> connected; [SDP]/[CDP]/[Unknown] -> connected;
  confirmed DCP -> off; unplug keeps own off; then SDP/[Unknown]/host state -> reconnected; no ERROR); old Q4 "unplugged ->
  off" case now expects untouched. USB wiring 51/51, USB host tests 141/141 x3 unchanged.
