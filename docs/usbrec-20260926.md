## 3. ROM install tools with V75-usb in the recovery slot — no change needed
The rom-v1 engine (used unchanged by `rom-v3`) **does not gate on the recovery**: it backs the partition up, looks its sha up in
`RomFlashLayoutV1.RECOVERY_KNOWN` only to write a **label** (`report['recovery_state']`), and its XML guard refuses any program on the
recovery partition. With V75-usb the label reads `unknown` (cosmetic; the report also carries the sha). Checks that do gate (stock
system/vendor/dtbo, vbmeta, devinfo, GPT, BCB) do not involve recovery. So the `rom-v3` kit was **left byte-identical** (its pins,
`rom-v1-tools.json`, and "EDL tools byte-identical" claim stay true). For the next kit build, optionally add
`'8ecb8e9e…b304': 'v75usb-diagnostic'` to `RECOVERY_KNOWN` (label only) — flash/merge agent's file, not edited.
**Ordering constraint:** the v75u/v75r tools require **stock Android** booted (fingerprint check). Install V75-usb **before** rom-v3
(or after a ROM restore); once LineageOS is in boot/system, the recovery tools refuse to start (by design).
