# A6L r6m — camera preview metadata bridge

Follow-up to the physical r6l Camera failure. At 09:21:53 Paris time Camera
delivered frames, then SurfaceFlinger's RenderEngine aborted importing the
1600x1200 PRIVATE/NV12 preview. Android restarted its compositor and framework;
the kernel boot ID and uptime were unchanged. The complete failure snapshot
is in firmware/extracted/rom-r6l-20261003/camera-failure-snapshot.tar.gz.

## Cause and narrow change

The selected ro.hardware.gralloc=minigbm module was absent. Only gralloc.default
was installed. Mesa fell back to a module without lock_ycbcr and rejected
camera buffer metadata before GPU import, returning NULL with EGL_SUCCESS.

Add the existing generic gralloc.minigbm package, for both ABIs. Its CrOS perform
API links the same libminigbm_gralloc.so singleton/handle registry as the stable
mapper.minigbm. The _msm sibling would use a different singleton and is deliberately
not substituted. The selector was already correct and stays unchanged. Camera HAL,
NV12 processing, mapper/allocator, Mesa, GPU policy, kernel and device tree are
retained. Only the vendor image is built; r6l's system image is reused byte for byte.

## Validation

Forty-one actual-source metadata/handle/Mesa-helper ASan/UBSan checks pass.
The bounded NDK probe was reviewed and run on r6l for both ABIs. Hardware FD512
is confirmed: RGBA import passes and PRIVATE format34 fails with NULL/EGL_SUCCESS
in both, matching the physical crash. Probe submits no draw/swap; boot ID and
SurfaceFlinger/system_server PIDs remain unchanged. Source, host checks and probe
are in firmware/extracted/gralloc-bridge-20261003.

The vendor-only build passes in 4m40s. Actual EROFS comparison adds exactly
lib/hw/gralloc.minigbm.so and lib64/hw/gralloc.minigbm.so; all other payload files
are identical. The only other changes are generated build dates, r6m tag and
NOTICE. Both bridges use the original shared driver and mapper dependency;
ELF class, HAL export and CrOS module name are checked. Boot, dtbo and system
whole-image hashes match r6l. Laptop kit checksums and offline update plan pass.
