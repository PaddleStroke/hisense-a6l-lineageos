Changes:

- libcamera patch 0011 preserves Hi-846 PRIVATE/YUV preview modes below 30 fps
  and prevents an inverted FPS range. The old JPEG-only metadata caused CameraX
  initialization to abort. Isolated HAL compilation, IPA signature validation
  and an offline regression using the captured durations passed. Physical
  preview/capture remains to be tested after installation.
- rmtfs uses `-P -o /dev/block/by-name`, matching Android's actual partition
  links. The existing default read-only backing/shadow-write behavior remains.
  This addresses the missing modemst1 path preceding repeated modem crashes.
- `debug.mesa.fd.mesa.debug=sysmem` defaults to bypassing tiled freedreno
  rendering while retaining Adreno acceleration. Radio-disabled r6e crashed
  after pressing Power under default Mesa, but software rendering passed and
  Mesa sysmem passed two recorded sleep/wake cycles without GPU errors. This
  workaround may increase memory traffic; the underlying fault remains open.
  A further default-Mesa test after restarting SurfaceFlinger is needed to
  separate the sysmem option's effect from renderer/framework restart effects.
  A later r6e test froze while navigating to Display settings after a temporary
  1080×2160 layout change, with sysmem active and radio disabled. The cause is
  awaiting recovered logs; this workaround does not establish overall stability.
- Build marker is r6f; other r6e fixes and the debug adb key are retained.
- E-ink no longer performs the two-clear sequence on every side switch.
  Explicit Fast/Fastest apply to taps as well as scrolling; capture pauses
  while the panel is busy so input/replies remain serviced. Opaque LCD pixel
  conversion and row-wise resizing are accelerated with identical output in
  phone differential benchmarks. See [the investigation](eink-runtime-fixes-20261001.md).
  Panel latency/ghosting remain to be checked after installation. Full-area
  Android layout adaptation is a separate attended test, not part of this image.
