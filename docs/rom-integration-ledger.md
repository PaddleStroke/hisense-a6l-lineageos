# ROM integration ledger (rom-v2 / V75) — one line per feature

Maintained per the 25 Sep consolidation rule: every piece that is proven on the phone, or built and needed, is merged into the
ROM tree (kernel modules + V75 DT + vendor/system) and recorded here. First written by agent `merge` (25 Sep 2026) for
**rom-v2 = kit `rom-v2`** (build tag r1). Columns: **source** (agent doc) · **merged where** · **proven on phone?** (y = seen on
the phone; y~ = partly; n = built/offline only) + test id · **default** (on / gated by a property / off).

Paths: `rom/` = `device/hisense/a6l/rom/`, `K/` = `device/hisense/a6l/kernel/`, DT = `tools/build-rom-v2-dt.sh`
(V74 base.dtb + overlays in this order), modules = `rom/modules/*.txt` loaded by `rom/bin/a6l-modules.sh`.
