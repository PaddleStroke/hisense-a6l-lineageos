- lunch `lineage_gsi_a6l` + `aosp_target_release` **userdebug**, `m -j12 systemimage vendorimage` (pipeline default). Build 16:17 min (incremental).
- `A6L_KERNEL=r5`: stage script replaced all 122 staged modules with the r5 rebuilds (`kernel r5: 122 modules replaced`,
  `MODULE_ORDER PASS loaded 121`, `STAGE_ROM_V2_PREBUILTS_PASS`); boot.img with the r5 Image.
- `A6L_SEPOLICY_ROM=1`: ROM-level vendor policy (`rom/sepolicy/vendor`) compiled in, SELinux still **permissive**
  (cmdline) — the documented plan for the first install (release-prep: "first install (r4 or r5): userdebug, permissive,
  A6L_SEPOLICY_ROM=1"). The companion `rom/sepolicy/rc-enforcing.patch` **no longer applies** (init.qcom.rc,

  pipeline signs only with `A6L_RELEASE=1` (+ tools/release/sign-a6l-release.sh); the release keys in /home/a6l/.android-certs
  were not used. Consequence: switching to release keys later needs an EDL reinstall + data wipe (release-prep §OTA).
- Not in this build: A6L_FSTAB=fbe (FBE trial comes after the r5 RAM boot), A6L_RELEASE, the 0001 release-defaults patch.

## 4. Install proposal (NOT executed; existing tooling, docs/flash-20260924.md §5/§7, merge-20260925.md §9)
1. Stage the kit on the laptop (no phone access; ~2 GB scp): `bash tools/stage-rom-v2-kit-laptop.sh r5 rom-r5`
   → `~/A6L-usb-20260915/rom-r5/`, expect `LAPTOP_SHA_OK`.
2. Laptop, offline: `cd ~/A6L-usb-20260915/rom-r5 && python3 Verify-RomV1Stage.py` → `"passed": true`.
3. Phone: **stock Android booted** (not recovery: the runner checks fingerprint L1632.6.01.04, orange/unlocked, port 3-2,
   battery ≥ 60 %, ≥ 12 GB laptop free; it enters EDL with `adb reboot edl`). Then
   `python3 Launch-RomV1Install.py && tail -f rom-v1-install-launch.log` (12–20 min): full backups of boot, dtbo, misc,
   metadata, modemst1/2, fsg, fsc, persist, **recovery**, vbmeta, devinfo, vendor, system, userdata head/tail; refuses unless
   system/vendor/dtbo = 14 Sep stock hashes; writes boot, dtbo, vendor, system (EROFS bytes), zeroes the first MiB of metadata
   and userdata; readback; power off. **Recovery partition is not written**: the V74/V75 diagnostic recovery stays.
   Keep `capture-rom-v1-install/` (the only way back to stock) and copy it to the desktop `captures/`.
4. First boot (Power): orange-state warning, earlycon text, boot animation, setup wizard; first boot formats /data + dex2oat
   (3–5 min; QEMU 16 min under TCG). Checks as flash §7.2/§7.3 (+ r5: `dmesg | grep -E "disagrees|Unknown symbol|usercopy"` empty,
   `A6L_ROM ... done fails=0` for every group, `uname -r`, `iptables -m mark`).
5. Rollback: quick = fastboot menu → Recovery (diagnostic recovery unchanged); full = EDL + `Launch-RomV1Restore.py`
   (EDL entry from a non-stock state is still unproven, flash §5 — main open risk of the rollback path).

## 5. Open risks
- **r5 kernel never booted on the phone.** The kernel doc's step 1 (attended RAM boot of the r5 boot.img: module loads, no
  version/usercopy errors, display/touch/audio/radio/Wi-Fi) has not been done. Recommended before the eMMC install:
  RAM-boot `boot-r5/boot.img` from the V75 recovery flow, or accept that the first install is also the first r5 boot (rollback via EDL).
- **Mobile radio is OFF by default** in the source (`rom/rom.mk` `persist.vendor.a6l.radio=0`, "Pierre enables it"); the
  on-by-default switch lives only in the unapplied `rom/release/0001-release-defaults.patch`. Built as merged; to enable after
  install: `adb root; adb shell setprop persist.vendor.a6l.radio 1` + reboot (or apply 0001 and rebuild).
- Build marker still reads `ro.vendor.a6l.rom.build=r4` (rom.mk not bumped); identify r5 by the image hashes above.
- rc-enforcing.patch stale (see §1); SELinux permissive; genfs sysfs paths UNVERIFIED (release-prep).
- Test keys; FBE not enabled (A6L_FSTAB unset); kernel gaps: xt_quota2 (netd data alerts fail), dm-default-key, per-UID stats.
- Camera stays gated (`persist.vendor.a6l.camera=0`), no camera HAL; VoLTE off (Orange refuses VoPS); charger driver gated
  (persist.vendor.a6l.charger=0 → PMIC defaults; off-mode charging needs the build default = 1); series q6voice (F6 mute / F37
  volume) not shipped; F3/F49 modules and Wi-Fi HAL not phone-tested; libwifi-hal.so in out dated 25 Sep (unchanged dependency).
- Kit `rom-v1` install refuses if system/vendor/dtbo differ from the 14 Sep stock hashes (nothing has written them so far).
