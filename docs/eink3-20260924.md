## 1. Summary
- **DRM ownership, chosen design: the composer keeps the whole card and *leases* the e-ink to the service.**
  A small patch to `external/drm_hwcomposer` (`patches/external/drm_hwcomposer/0001-…patch`) adds
  `vendor.hwc.drm.ignore_connectors` (e-ink = `mode:384x725`, so it does not depend on DSI-1/DSI-2 numbering) — the
  connector is never attached, SurfaceFlinger never sees a 2nd display — and a **lease server** on the abstract socket
  `@a6l.hwc.lease` that hands `vendor.a6l_epdd` a DRM lease of {e-ink connector, a free CRTC, its free primary planes}.
  The leased CRTC/planes stay bound to a placeholder pipeline inside the composer, so it can never use them itself.
  `a6l_epdd --no-master` never opens `/dev/dri/card*` at all (connector found in sysfs, the lessee fd is the only DRM fd
  it holds), so it can never steal DRM master from a (re)starting composer.
- **E-ink service `vendor.a6l_epdd`** (`src/a6l_epdd.c`, v4 = v3 + productization): init socket `a6l_epd` with one reply
  line per command, pixels sent inline (`frame 720 1440 MODE` + 1 036 800 bytes), waveform sources in order
  persist copy → `/data/vendor/epd` cache → **panel NOR read-only via spidev** (only opcodes 0x9F/0x05/0x03 can be sent,
  JEDEC must be c2 25 33, two identical passes, then cached) → vendor-image fallback copy; lease re-acquired and the
  update re-driven when the composer restarts; CRTC off after `idle_off_s` (default 30 s); wakelock during a drive.
  `libtcon_eink.so` shipped as `/vendor/lib64/libtcon_eink.so` (stock blob, `cc_prebuilt_library_shared`).
- **Controller `vendor.a6l_eink`** (`src/a6l_eink_mirror.c` v2 + `src/eink_logic.c`): e-ink key 616 (short = mirror
  on/off, long ≥ 0.8 s = full clear), `persist.vendor.eink.mode` (off|mirror) and `persist.vendor.eink.reading` (0|1),
  front capture from the LCD CRTC planes (DRM, no master, CAP_SYS_ADMIN), automatic waveform policy (quality /
  A2 bursts / settle / periodic clears; reading = REGAL partial + periodic GC16, no A2), pause while the LCD is off.
  **Rear touch**: always `EVIOCGRAB`bed (Android never sees raw rear touches); in mirror mode contacts are mapped onto
  the mirrored picture and re-injected through a uinput touchscreen `a6l-eink-rear-touch` (1080×2340, internal, display
  0); off → dropped.
- **Verified offline**: logic unit tests 50/50; host end-to-end epdd↔mirror over the real socket protocol (fake TCON)
  14/14 incl. key + rear-touch mapping; **QEMU `--dry` with the stock library + real waveform: all 13 updates
  byte-identical to v2/v3, both through PGM files and through the new inline `frame` path**; NDK builds (0 warnings);
  composer patch applies cleanly and compiles (0 errors/0 new warnings); vendor SELinux compiles with the AOSP policy
  (monolithic checkpolicy, neverallows checked). Details §6.
- **Not tested at all**: the lease server on a real kernel, the lessee modeset of the e-ink while the LCD runs, DRM
  capture (UBWC/linear?), uinput injection into InputReader, SELinux policy compile (`m selinux_policy`) and enforcing
  behaviour, the NOR read through spidev in the ROM (needs the flash-read DT node + spidev).

## 2. DRM ownership — options evaluated
| Option | Verdict |
|---|---|
| Separate DRM device for the e-ink | **Not possible without a new kernel driver.** LCD (DSI0) and e-ink (DSI1) are two INTFs of the same MDSS/DPU (one msm KMS device; V71 dump: crtc-0/plane-0 LCD, crtc-1/plane-1 e-ink). `separate_gpu_kms=1` only splits the GPU render device off. |
| sysfs `status=off` + pidfd lease (M1) | Works from a root shell next to an unpatched composer (kept for the RAM session). Not for the ROM: `pidfd_getfd` needs ptrace rights over the composer (SELinux `process ptrace` on a HAL — not acceptable) and the forced-off connector reports no modes. |
| Composer drops master (`ro.vendor.hwc.drop_drm_master`) | Breaks the composer's own commits. |
| `video=DSI-2:d` on the cmdline | Kernel-level disable; the service could not modeset it either. |
| **Patched composer: ignore + lease server (chosen)** | Clean ownership (the composer is the only master, the kernel enforces the split), no ptrace, survives composer restarts (lease re-requested), survives service restarts (new request revokes the old lease), composer can never reuse the leased CRTC/planes. ~250 lines, upstream-style. |

**Where the mirror runs.** A system-side mirror (SurfaceFlinger screenshot, as in M1) would have to talk to the vendor
service across the Treble boundary (socket between core and vendor = neverallow unless a "violator" attribute is used,
or a frozen stable-AIDL HAL). The composer lease also forces the service to be vendor. So both processes are vendor and
the front picture is read from the LCD CRTC's planes (what is actually scanned out, always the physical portrait
1080×2340 — no rotation handling needed for picture or touch). Cost: CAP_SYS_ADMIN for GETFB2 handles and linear
buffers only (§8). The screencap source stays available for the RAM session.

## 3. Behaviour of the installed ROM
- Boot: `on property:init.svc.vendor.hwcomposer-3=running` starts both services. epdd waits (≤ 60 s) for the lease, then
  does the stock start-up clear (INIT flash + reset to white, ~2.5 s) — the rear screen flashes once per boot, like stock.
- Mode `off` (default): the e-ink keeps whatever it shows (e-paper, no power), CRTC off after 30 s, rear touch dropped.
- Short press of the e-ink key: mirror on → clear flash, then the front screen appears (720×1440, white 27-px side bars).
  Changes: tap → one GC16 (~0.9 s); scrolling → A2 black/white updates (~0.5 s each, latest frame wins); stop → one
  clean update after 1 s; every 10th clean update is preceded by a full clear. Rear touches act on the front.
- `persist.vendor.eink.reading=1`: no A2 at all; one update when the content is still for 1 s — REGAL partial
  (stock "reading", no flash) for changes < 60 % of the tiles, GC16 above (page turn); every 8 partial updates a forced
  GC16 refresh of the same picture; a clear every 20 GC16 updates.
- Long press (≥ 0.8 s): full clear flash (then the picture is redrawn when mirroring).
- Front screen off → mirror paused (picture kept, touch not forwarded); on → resumes.
- Settings: `persist.vendor.eink.{mode,reading,touch_transform,idle_off_s,interval_ms,clear_every}`,
  state `vendor.eink.state` (off / mirror / mirror-reading / mirror-paused / mirror-no-epdd).
- Rear touch transform (raw 720×1440 → panel orientation): `persist.vendor.eink.touch_transform` = combination of
  `swap`, `invx`, `invy` (default none) — to be set from test R6 (§7).

## 5. Hand-off to the `flash` agent (nothing here was built with `m`)
1. `bash device/hisense/a6l/eink/extract-eink-blobs.sh` (copies `libtcon_eink.so` + this unit's waveform into
   `eink/proprietary/`, git-ignored; eink3-04 already ran it in the repo copy). Without it the `Android.bp` prebuilts fail.
2. `bash device/hisense/a6l/eink/patches/apply-patches.sh /home/a6l/android/a6l-lineage24` (drm_hwcomposer; idempotent,
   `git apply --check` first). Rebuild the composer (`android.hardware.composer.hwc3-service.drm`).
3. `lineage_gsi_a6l.mk`: `$(call inherit-product, device/hisense/a6l/eink/eink.mk)` →
   PRODUCT_PACKAGES `a6l_epdd a6l_eink_mirror libtcon_eink a6l_epd_waveform_fallback`, keylayout + idc copies,
   PRODUCT_VENDOR_PROPERTIES `vendor.hwc.drm.ignore_connectors=mode:384x725 vendor.hwc.drm.lease_socket=a6l.hwc.lease
   persist.vendor.eink.mode=off persist.vendor.eink.reading=0`. The rc (`a6l_eink.rc`) is installed by `a6l_epdd`.
4. `BoardConfig.mk`: `BOARD_VENDOR_SEPOLICY_DIRS += device/hisense/a6l/eink/sepolicy/vendor`. Build `selinux_policy`
   first; if it fails, the error names the rule — or drop the line and keep SELinux permissive for the first install.
5. `/vendor/etc/ueventd.rc`: include `config/ueventd.eink.rc` (epd_power 0660 system, spidev) — set
   `A6L_EINK_SHIP_UEVENTD := true` if nothing else ships a vendor ueventd.rc, else append the two lines to yours.
6. Kernel/DT for the ROM boot image: the V73/V74 e-ink modules (`panel-a6l-epd-dsi.ko` with `epd_power` +
   `bringup_status`, `tps65185.ko`, tc358762 bridge path as in bundle-v74), `edt-ft5x06.ko` (rear touch),
   `CONFIG_INPUT_UINPUT=y`, DRM leases (core, always on). Optional (NOR read): `CONFIG_SPI_QUP`, `CONFIG_SPI_SPIDEV`
   and the `a6l-eink-flash-read.dtso` SPI node (without it the persist/cache/vendor copies are used).
7. Nothing in `diagnostic/` changes; the RAM-session tools stay as they are.

## 8. Risks and unknowns
- **Lease server on msm (untested)**: needs {connector, crtc-1, plane-1} to be leasable and legacy SetCrtc on the lessee to
  find crtc-1's primary in the lease. The server leases *all free* primary planes that can feed the CRTC; the LCD
  pipeline binds the lowest-id primary (plane-0) first, so plane-1 (= crtc-1's primary per the V71 dump) is free.
  If the kernel's crtc→primary mapping differs, SetCrtc fails with EACCES → visible in E2 (then lease the
  pipeline-bound primary instead: 2-line change in `LeaseServer::CreateLease`).
- **Composer writeback / virtual displays**: the leased CRTC is bound to a placeholder, so a writeback pipeline cannot
  take it; if the composer ever needs 2 CRTCs for the LCD it would now fail instead of stealing the e-ink's.
- **Re-enable after idle-off / suspend** (E11): the e-ink modeset + bridge bring-up has only ever run at module load
  or once per session (r113-style non-recovery risk). If it misbehaves: `setprop persist.vendor.eink.idle_off_s 0`
  (CRTC stays on, ~DSI1 stream power) and look at the panel driver's `.enable` retries.
- **DRM capture**: needs linear XRGB/ABGR scanout buffers. The ROM stack (minigbm + ANGLE/SwiftShader, CPU-mapped)
  should be linear; a freedreno/UBWC stack would not be (`fb modifier … compressed` in the log → the mirror cannot read
  the screen; then a system-side capture (SurfaceFlinger screenshot / virtual display) is needed, which crosses the
  Treble boundary — see §2 of `docs/eink-android-integration-20260923.md`). Capture cost is unmeasured (10 MB read per
  capture at 4 Hz from write-combined memory; raise `persist.vendor.eink.interval_ms` if the UI stutters).
- **SELinux**: compiles monolithically with the AOSP policy (neverallows OK), but the split vendor build
  (`m selinux_policy`, public-API-only view + Lineage policy) was not run, and the rules are written from reading, not
  from denials. First install should run permissive; E14 collects the denials. The mirror needs `sys_admin` (GETFB2
  handles) — allowed, but worth replacing later (see the DRM-capture note). `/dev/dri` and the composer binary are not labelled by
  the generic arm64 board at all (both added in our file_contexts; identical duplicates are harmless).
- **sysfs paths** assumed for genfs/ueventd: `/sys/devices/platform/soc@0/c900000.display-subsystem/c996000.dsi/
  c996000.dsi.0/epd_power` and the TPS65185 on `c176000.i2c`. a6l_epdd logs the real path at start
  (`rail switch … (label this path …)`) — compare in E2/E13.
- **Rear touch orientation** unknown until R5/E8 (transform property, no rebuild needed). The rear picture is the
  physical portrait framebuffer, so landscape apps appear rotated on the rear exactly like on the front, and the touch
  mapping stays correct without rotation handling.
- **Key 616 → MACRO_1**: apps receive MACRO_1 key events (none known to react). The handler reads evdev directly, so it
  works even if the framework assigns MACRO_1 a meaning later; remove the kl line if it misbehaves.
- **Boot flash**: the stock-style start-up clear flashes the panel at every boot (`--no-startup-clear` exists).
- **NOR read in the ROM** needs the SPI node + spidev; without it the persist/cache/vendor copies are used (the vendor
  copy is this unit's 20 Sep read, identical to what the RAM sessions used). Nothing can write the NOR: only
  0x9F/0x05/0x03 are sendable, any other opcode aborts the process.
